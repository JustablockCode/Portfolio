About

Custom 4.19 kernel for the Xiaomi Redmi 9 / lancelot. A lightweight build focused on stability, root access, and smooth performance on older hardware.

Android Base

Language

What's In It

  • ReSukiSU v4.2.0-rc2 — Magisk-based root with systemless overlay
  • SUSFS v2.3.0-R28 — Kernel-level file system for smoother I/O
  • WireGuard VPN — Full kernel-level tunneling support
  • NoMount — Avoids unnecessary mount operations on boot
  • Tested on Xiaomi Redmi 9 / lancelot device
